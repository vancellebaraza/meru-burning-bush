# Meru Burning Bush

Build a multi-page website for BURNING BUSH MINISTRIES INTERNATIONAL, a church in Meru, Kenya. Motto: "In Burning Bush Ministries, everybody is somebody."

Stack: React + Vite + TypeScript + Tailwind, React Router. Keep it clean and easy to move to GitHub. Do NOT set up any backend or database. We will connect Supabase ourselves later. Use local mock data files for now.

Brand: white, red and gold. White background, red as the main accent, gold for highlights. Warm, welcoming, modern. Mobile first.

Pages (with a shared navbar and footer):
- Home: hero (vision: "Teach the undiluted Word of God and develop leaders"), service times strip, four pillars (Church Planting, Ministry Leadership Training, Worldwide Evangelism, Marketplace Ministry), next event banner (Gathering of Champions Conference, 23-27 Nov 2026), give CTA
- About: story, vision, mission, core values
- Leadership: ministry board and local church pastors
- Services & Events: weekly programmes and upcoming events
- Ministries: Children, Youth, Worship, Outreach, Bible Study, Ministry of Helps
- Sermons: grid of video/audio/photo cards with placeholder items
- Give: bank and Paybill details, project fund card
- Contact: phone, email, address, map placeholder, contact form (UI only)

Footer: address (Mwiteria, Eastern Bypass, next to Kiambogo Coffee Factory, Meru), phones 0794464082 / 0105434899, email merubbc2010@gmail.com, social icons as placeholders.

Use placeholder images and a text logo for now. Keep the components small and reusable, and put all page content in separate data files so it's easy to edit.
